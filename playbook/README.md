# 원칙집 (Playbook) — 봇의 "머릿속"

봇이 사람 트레이더처럼 **자기 원칙을 기억하고, 그날의 생각을 남기고, 원칙을 다듬어 가는** 공간. 전부 사람이 읽고 고칠 수 있는 마크다운이다.

| 파일/폴더 | 내용 | 누가 쓰나 |
|---|---|---|
| `principles.md` | **현재 유효한 원칙.** 봇이 매 판단마다 읽는다 | 사용자와 토론 후 갱신 (봇 단독 수정 금지) |
| `principles-log.md` | 원칙 변경 이력: 언제·무엇을·왜·출처(토론/자료/데이터)·결정자 | 원칙을 바꿀 때마다 반드시 한 줄 추가 |
| `journal/YYYY-MM-DD.md` | 봇의 일지: 오늘 시장을 어떻게 봤고, 무엇을 했/안 했고, 왜 그랬는지 | 봇이 판단할 때마다 자동 기록 |
| `proposals/` | 봇이 스스로 학습해서 낸 **원칙 변경 제안** (근거 데이터 포함) | 봇 → 사용자가 검토·토론 후 승인/기각 |
| `sources/` | 사용자가 제공한 자료 원본과 요약(digest) | 사용자 제공, 봇이 요약 |

## 원칙이 바뀌는 방법
1. **토론**: 사용자가 자료·의견을 주면 논의 → 합의되면 `principles.md` 수정 + `principles-log.md` 기록.
2. **자율 학습**: 봇이 리뷰 세션(기획서 6.4)에서 데이터로 원칙 변경안을 `proposals/`에 작성 → 사용자 승인 후 반영.
   - 예외: 익절·손절·타임스톱 **수치**는 정해진 범위 안에서 자동 승격 가능 (기획서 6.4). 이 경우에도 `principles-log.md`에 남긴다.
3. **금지**: 리스크 가드·킬스위치·롱 온리를 학습이 바꾸는 것. 표본이 부족한 결과로 원칙을 뒤집는 것.

## principles.md 읽는 법
- 맨 위 **한눈에 보기** 표가 지금 봇이 쓰는 값입니다.
- ✅ 확정 = 내가 정한 것 / 🟡 임시 = Claude가 가정한 것(확인 필요) / 🤖 판단 습관 / 🔒 안전장치 / 💬 토론 후보(아직 안 씀).
- 번호(P-011 등)는 일지와 판단 기록에서 "어떤 원칙 때문에"를 가리킬 때 씁니다.
- 숫자로 강제되는 값(익절·손절 %)은 `application.yml`에 있고, 원칙 표의 값과 같아야 합니다.
