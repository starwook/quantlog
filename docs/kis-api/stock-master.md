# KIS 국내 종목 마스터 파일

종목 추가 화면의 검색 대상(`stock_master` 테이블)을 채우는 원본. **2026-10-07 실제 파일을 받아 바이트 단위로 검증**했다 (GPT 조사 결과의 필드 수·길이 불일치를 실파일로 바로잡음). 파서: `stockmaster/StockMasterParser.kt`.

## 받는 곳
- `https://new.real.download.dws.co.kr/common/master/kospi_code.mst.zip`, `kosdaq_code.mst.zip` (KONEX는 `konex_code.mst.zip`, 우리는 안 씀)
- **인증 불필요**(앱키·토큰 없이 GET). 하루 여러 번 갱신(KIS 안내: 06:00 ~ 18:55 사이 13회, 08:45 포함). 우리는 매일 08:50 에 받는다.
- ETF·ETN·ELW 는 별도 파일이 아니라 코스피/코스닥 파일 안에 섞여 있다(증권그룹 `EF` ETF, `EN` ETN, `RT` 리츠, `BC` 수익증권, 코스닥은 `FS` 외국주권, `DR` 예탁증서).
- 크기: KOSPI 약 0.74MB(2,575건), KOSDAQ 약 0.52MB(1,825건) — 압축 해제 후.

## 레코드 형식
- 인코딩 **CP949(MS949)**, 줄바꿈 `\n`(`\r` 없음), 한 줄 = 한 종목, 모든 줄이 같은 바이트 길이.
- 한글은 2바이트라 문자 index 가 아니라 **바이트 offset** 으로 자른다.

| 구간(바이트) | 내용 |
| --- | --- |
| 0..9 | 단축코드(공백 패딩). 문자열로 다룬다(`005930`, 영문 섞인 `0000D0`, `Q500067`) |
| 9..21 | 표준코드(`KR7005930003`) |
| 21..61 | 종목명(40바이트, 공백 패딩) |
| 61.. | 고정폭 필드. **KOSPI 70개 227바이트(줄 전체 288), KOSDAQ 64개 221바이트(줄 전체 282)** |

(공식 Python 정제 코드가 `row[-228:]`/`row[-222:]` 를 쓰는 건 줄 끝 `\n` 1바이트를 포함해서다.)

## 뒷부분 필드(순서대로, 괄호는 바이트)
KOSPI: 증권그룹(2) 시총규모(1) 업종대(4) 업종중(4) 업종소(4) 제조업(1) 저유동성(1) 지배구조(1) K200섹터(1) K100(1) K50(1) KRX(1) **ETP(1)** ELW발행(1) KRX100(1) KRX자동차·반도체·바이오·은행(각1) SPAC(1) KRX에너지화학·철강(각1) 단기과열(1) KRX미디어통신·건설(각1) Non1(1) KRX증권·선박·보험·운송(각1) SRI(1) 기준가(9) 매매단위(5) 시간외단위(5) **거래정지(1) 정리매매(1) 관리종목(1)** 시장경고(2) 경고예고(1) 불성실공시(1) 우회상장(1) 락구분(2) 액면변경(2) 증자(2) 증거금(3) 신용가능(1) 신용기간(3) 전일거래량(12) 액면가(12) 상장일(8) 상장주수(15) 자본금(21) 결산월(2) 공모가(7) **우선주(1)** 공매도과열(1) 이상급등(1) KRX300(1) KOSPI(1) 매출액(9) 영업이익(9) 경상이익(9) 순이익(5) ROE(9) 기준년월(8) 시가총액(9) 그룹사(3) 신용한도초과(1) 담보대출(1) 대주(1)

KOSDAQ: 증권그룹(2) 시총규모(1) 업종대(4) 업종중(4) 업종소(4) 벤처(1) 저유동성(1) KRX(1) **ETP(1)** KRX100(1) KRX자동차·반도체·바이오·은행(각1) SPAC(1) KRX에너지화학·철강(각1) 단기과열(1) KRX미디어통신·건설(각1) 투자주의환기(1) KRX증권·선박·보험·운송(각1) KOSDAQ150(1) 기준가(9) … 이후는 KOSPI 와 같고 **KOSPI 전용 `KOSPI(1)` 필드만 없다**.

값 의미(실파일 확인): 거래정지·관리종목 `Y`/`N`, 우선주 `0` 보통주, 상장일 `YYYYMMDD`, 기준가 원 단위 9자리. 삼성전자(005930)로 확인: 그룹 `ST`, 상장일 19750611, 기준가 272000. 에코프로비엠(247540, KOSDAQ): 상장일 20190305.

## 우리가 저장하는 값
단축코드·표준코드·종목명·시장(KOSPI/KOSDAQ)·증권그룹·거래정지·관리종목. `EF`(ETF)면 종목 추가 시 ETF 플래그를 자동으로 켠다(국내 ETF 는 증권거래세 없음). ETN 은 ETF 가 아니다.
