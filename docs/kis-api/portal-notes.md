# KIS Developers 포털 원문 발췌 (2026-09-25 확인)

출처: https://apiportal.koreainvestment.com → API 문서 → [해외주식] 주문/계좌 (브라우저로 열어 개요 항목을 옮겨 적음. 포털이 JS 렌더링이라 파일 다운로드가 안 됨)

## 해외주식 주문 [v1_해외주식-001] — `POST /uapi/overseas-stock/v1/trading/order`

- 모의 TR ID: (미국매수) `VTTT1002U` (미국매도) `VTTT1001U`  ← 실전은 `TTTT1002U` / `TTTT1006U`
- 모의투자의 경우, **모든 해외 종목 매매가 지원되지 않는다. 일부 종목만 매매 가능.**
- 해외주식 서비스 신청 후 이용 가능 (해외증권 거래신청).
- **해외 거래소 운영시간 외 API 호출 시 에러.** 미국주식 주간주문은 "해외주식 미국주간주문"을 이용.
- 운영시간(한국시간):
  - 미국 정규장: 23:30 ~ 06:00 (**서머타임 22:30 ~ 05:00**)
  - **프리마켓: 18:00 ~ 23:30 (서머타임 17:00 ~ 22:30), 애프터마켓: 06:00 ~ 07:00 (서머타임 05:00 ~ 07:00) 시간대에도 주문 가능**
  - 일본 09:00~11:30 / 12:30~15:00, 상해 10:30~16:00, 홍콩 10:30~13:00 / 14:00~17:00
- 주문구분(`ORD_DVSN`): 모의투자 미국 매수/매도는 `00`(지정가)만 가능.
- 2025-08-14부터 상장주식수 1% 초과 주문도 접수 가능 (Open API는 별도 안내 화면 없이 바로 접수).
- 응답 `output`: `KRX_FWDG_ORD_ORGNO`, `ODNO`(주문번호), `ORD_TMD`(주문시각).

## 해외주식 미국주간주문 [v1_해외주식-026] — `POST /uapi/overseas-stock/v1/trading/daytime-order`

- 실전 TR ID: (주간매수) `TTTS6036U` (주간매도) `TTTS6037U`
- **모의 Domain: 모의투자 미지원 / 모의 TR ID: 모의투자 미지원**
- 주간거래(장전거래) 시간: 한국시간 10:00 ~ 18:00 (서머타임 동일). 시간 외 호출은 에러.
- 일부 종목만 매매 가능. 지정가만 가능.
