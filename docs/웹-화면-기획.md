# 웹 화면 기획 — "내가 웹에서 무엇을 확인하는가"

> 상태: 초안 v0.1 (2026-09-25) / 상위 문서: [기획서.md](기획서.md)
> 기준: 프론트는 Thymeleaf 서버 렌더링 + 차트 1종, **모바일(아이폰 12 Pro, 390×844) 우선**. 공개 범위·규제는 보류(기획서 10장) 상태이므로 **1차는 관리자(나) 전용**, 공개는 마지막 단계.

## 1. 웹이 답해야 하는 질문

봇을 돌리는 동안 내가 웹을 여는 이유는 결국 다섯 가지다. 화면은 이 질문 하나당 하나만 만든다.

| # | 질문 | 답하는 화면 |
|---|---|---|
| 1 | 지금 봇이 살아 있고, 계좌는 어떤 상태인가? | 대시보드 |
| 2 | AI가 무엇을 왜 결정했고, 그 결과는 어떻게 됐나? | 판단·거래 피드 → 판단 상세 |
| 3 | 결국 돈을 벌고 있나? 시장(벤치마크)보다 나은가? | 성과 |
| 4 | 지금 어떤 규칙·프롬프트로 돌고 있고, 언제 바뀌었나? | 전략 |
| 5 | 문제가 생겼을 때 멈추거나 한도를 확인할 수 있나? | 관리 (관리자 전용) |

## 2. 내비게이션 (중복 제거 후)

| 요소 | 이동 | 이 요소가 없으면 못 하는 일 |
|---|---|---|
| 로고 | 대시보드(`/`) | (홈 탭을 따로 두지 않음 — 로고가 홈) |
| 거래 | `/decisions` | 과거 판단·거래 열람 |
| 성과 | `/performance` | 수익률·벤치마크 비교 |
| 전략 | `/strategy` | 규칙·버전 이력 확인 |
| 관리 (관리자만) | `/admin` | 킬스위치, 한도, 시스템 상태 |

**현재 구현된 임시 메뉴 (2026-09-30, 로컬 개발용):** 계좌(`/`) · 관심종목(`/chart/...`, 종목별 분봉 차트 + 수동 매수/매도) · 백테스트(`/backtest/...`) · 설정(`/settings`). 설정은 종목별 자동매수·익절/손절·마틴게일 값(`symbol_strategy`)을 화면에서 바꾼다. **인증이 없어서 배포 전에 접근 제한이 필요**하다. 위 표의 정식 메뉴로는 화면이 갖춰지면 옮긴다.

**뺀 것과 이유**
- "홈" 탭: 로고와 중복.
- "보유 종목" 탭/페이지: 대시보드 안에 인라인으로 이미 나온다. 청산된 포지션 이력은 거래 피드의 "청산" 필터로 본다.
- "판단" 과 "거래"를 분리하지 않는다: 하나의 피드에서 유형 필터로 나눈다.
- "전체 종목 시세", "최신 뉴스" 같은 관례적 섹션: 이 서비스의 가치는 **봇의 판단 기록**이라 넣지 않는다.

## 3. 화면별 명세

### 3.1 대시보드 `/`

**시장 선택**: 상단에 `미국 | 국내` 토글. 통화(USD/KRW)를 합산하지 않기 위해 "전체"는 두지 않는다.
- **기본값**: 현재 정규장이 열린 시장. 둘 다 닫혀 있으면 가장 최근에 거래한 시장.
- **필터를 따르는 섹션**: 계좌 요약, 보유 종목, 오늘의 판단, 벤치마크 미니차트.
- **필터와 무관(항상 두 시장 모두)**: 봇 상태 바, 시장 개장 상태.

```
┌───────────────────────────┐
│ quantlog          [관리]   │
│ 거래  성과  전략            │
├───────────────────────────┤
│ ● 봇 가동중  마지막 판단 10:32 │  ← 가동/정지/오류, 클릭 시 /admin
│ 미국 ○닫힘(22:30 개장) 국내 ○휴장 │
├───────────────────────────┤
│ [미국] 국내                │
│ 평가금액   $10,412.30      │
│ 누적손익  +$412.30 (+4.1%) │
│ 오늘손익   -$23.10 (-0.2%) │
│ vs S&P500  +1.3%p          │
├───────────────────────────┤
│ 보유 종목 (3)              │
│ AAPL  2주  평단 180.1      │
│       현재 187.5  +4.1% ✔익절가 근접│
│ KO    5주  ...  -1.2%      │
├───────────────────────────┤
│ 오늘의 판단 (최근 5건)     │
│ 22:40 매수 NVDA  ·근거 요약 │
│ 22:10 보류 ·"변동성 확대…" │
│            [거래 전체 보기 →]│
├───────────────────────────┤
│ ※ 모의투자 실험 기록입니다… │  ← 하단 고정 고지
└───────────────────────────┘
```

- 보유 종목은 **가로 스크롤이 아니라 세로 목록**으로 쌓는다 (화면 하단이 비어 보이지 않도록).
- 종목 행에는 ±3% 기준선까지의 거리를 함께 보여준다 (익절/손절 임박 여부).
- **빈 상태**: 보유 종목이 없으면 "보유 종목이 없습니다. 봇이 진입 신호를 기다리는 중입니다."
- **오래된 데이터 표시**: 마지막 갱신 시각을 항상 표기. KIS 응답 실패 시 배너 "잔고를 갱신하지 못했습니다 (마지막 성공 10:32)".

### 3.2 판단·거래 피드 `/decisions`

한 줄 = 한 번의 판단(AI가 결정한 사이클). 항목은 시간 역순.

| 필터 | 값 | 기본값 |
|---|---|---|
| 유형 | 거래만 · 전체(보류 포함) · 매수 · 익절 · 손절 · 리스크가드 차단 | **거래만** (보류는 하루 수십 건이라 피드를 덮으므로 기본에서 제외) |
| 시장 | 전체 · 미국 · 국내 | **전체** (금액은 각 통화로 표기, 합산 안 함) |
| 기간 | 오늘 · 7일 · 30일 · 전체 | **30일** |

- 필터 컨트롤은 목록 **위**에 둔다.
- **페이지네이션**: 페이지당 20건, 하단에 이전/다음 + "총 N건 중 21–40". `?page=2&type=trade&market=all&days=30` 로 URL에 상태를 보존한다.
- **빈 상태**: "조건에 맞는 판단이 없습니다. 필터를 완화해 보세요." (필터 초기화 링크)
- 행 구성: 시각 · 시장 배지 · 유형 배지 · 종목 · 수량@가격 · 결과(청산이면 손익%) · 근거 한 줄. 모바일은 표가 아니라 카드 목록.

### 3.3 판단 상세 `/decisions/{id}`

이 서비스의 핵심 화면. 위에서 아래로 **입력 → 판단 → 통제 → 실행 → 결과** 순서.

1. **그 시점의 입력**: 시세 스냅샷(지수, 종목 가격), 보유 포지션, 시장 개장 상태
2. **AI 결정**: `action / symbol / qty / confidence` + `reasoning` 전문
3. **리스크 가드**: 통과 / 차단 (차단이면 어떤 규칙 때문인지)
4. **주문·체결**: 주문번호, 지정가, 체결가, 수수료
5. **사후 결과**: 청산됐다면 익절/손절, 보유 기간, 손익. 아직 보유 중이면 현재 평가손익
6. **원문 (관리자 전용)**: 프롬프트/응답 원문, 모델·프롬프트 버전, 토큰 사용량

"이전 판단 / 다음 판단" 이동 링크 제공.

### 3.4 성과 `/performance`

| 섹션 | 내용 | 시장 필터를 따르나 |
|---|---|---|
| 수익률 곡선 | 내 계좌 vs 벤치마크 (미국: S&P500 또는 NASDAQ, 국내: KOSPI) + 기준선(무작위 진입 +±3%) | 따른다 |
| 핵심 지표 | 누적수익률, 승률, 손익비, 거래당 기대값, MDD, 거래 수 | 따른다 |
| 전략 버전별 비교 | 버전 v1/v2… 별 동일 지표 나란히 | **무관** (버전 비교가 목적이라 항상 전체 시장) |
| 표본 경고 | 거래 30건 미만이면 "통계적으로 의미 없음" 배지 | — |

- 시장 필터 기본값은 대시보드와 동일 규칙, 기간 기본값은 "전체 기간".
- 수익률은 **현지 통화 기준(환차익 제외)** 임을 화면에 명시. 환율 반영은 2단계.
- 비용(수수료·세금) 차감 후 순수익률을 기본으로 보여주고 총수익률은 보조.

### 3.5 전략 `/strategy`

- 현재 적용 중: 청산 규칙(±3%), 리스크 가드 한도, AI 모델·프롬프트 버전
- 변경 이력(changelog): 버전 · 시작일 · 변경 요지 · 그 버전의 거래 수/성과 링크(성과 화면의 버전 비교로 이동)
- **현재 원칙**: `principles.md` 전문 표시 (확정/가설 상태 배지), 변경 이력(`principles-log.md`), 토론 대기 후보
- **일지**: 날짜별 봇의 생각(`journal/`)을 읽는 뷰. 판단 상세에서 "사용한 원칙 ID"로 원칙에 링크 — 기획서 6.5
- **학습 노트**: 주간 리뷰 세션 결과(반사실 스윕 표, AI가 제안한 다음 버전과 근거, shadow 검증 현황, 승격/기각 이력) — 기획서 6.4
- 학습 노트(선택): 공부한 개념(매물대, 금리 등)과 전략 반영 여부

### 3.6 관리 `/admin` (관리자 전용, 인증 필수)

| 블록 | 내용 |
|---|---|
| 킬스위치 | 즉시 정지 / 재개 버튼 + 확인 대화상자 + 현재 상태 |
| 시장별 on/off | 미국·국내 각각 봇 활성화 스위치 |
| 리스크 한도 | 현재 값 표시 (변경은 1차엔 설정 파일, 화면에선 읽기 전용) |
| 시스템 상태 | KIS 토큰 만료 시각, 최근 API 오류 10건, LLM 호출 수/비용, 마지막 사이클 시각 |

주문을 화면에서 직접 내는 기능은 **만들지 않는다** (봇 외 주문 경로를 늘리지 않음).

## 4. 공통 규칙

- **하단 고지**: sticky footer 패턴 (`body: flex column, min-height: 100vh`, main `flex: 1`). 콘텐츠가 짧아도 바닥에 붙는다. 문구: "개인 실험 기록이며 투자 권유가 아닙니다. 과거 성과는 미래를 보장하지 않습니다."
- **시간 표기**: KST 기본, 미국 시세에는 현지 시각(ET) 병기.
- **통화 표기**: `$`/`₩`, 통화가 다른 값은 절대 합산하지 않는다.
- **로딩/에러**: 서버 렌더링이므로 페이지 자체는 즉시 뜬다. 외부(KIS) 조회 실패 시 마지막 성공 값 + 경고 배너. 차트는 데이터가 없으면 안내 문구.
- **접근 제어**: 1차는 로컬/사설 접근 + 관리자 로그인. 공개 단계에서 "지연 공개 + 원문 제외" 뷰를 별도로 만든다.

## 7. 구현 순서 제안

| 단계 | 내용 | 선행 조건 |
|---|---|---|

## 8. 미결 사항

1. 기본 시장 토글 규칙(개장 중 시장 우선)이 맞는가? 아니면 항상 미국 고정?
2. 성과 벤치마크: 미국은 S&P500 / NASDAQ 중 어느 쪽?
3. 관리자 인증 방식: 단일 비밀번호 로그인 vs Spring Security 폼 로그인?
4. 알림(봇 오류, 익절/손절 발생) 필요? 필요하면 채널(텔레그램/이메일)은? — 알림 발송은 규제·비밀 관리 이슈가 있어 별도 결정.
